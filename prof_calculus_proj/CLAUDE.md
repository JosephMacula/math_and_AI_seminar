The goal of this project is to create a web application where my calculus students can interact with a specially tuned claude agent called "Professor Calculus". Professor Calculus is designed to ask students questions about a user-specified range of material, evaluate their responses, and provide feedback until the student supplies an acceptable answer. At this point, Professor Calculus asks the student another question, and the process continues. The difficulty of the questions should gradually increase, with the first question being basic and/or easy.

2. You must never fabricate claims about the code you are writing.
